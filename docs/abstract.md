# Abstract

We study a fitted error-operator coefficient associated with the Gauss-Legendre arithmetic-geometric mean algorithm for π. For consecutive lower approximants π_n, define

\[
\alpha_n=-\frac{\pi_{n+1}-\pi}{\pi_{n+1}-\pi_n}.
\]

Using Brent's theta-function expansion, we prove

\[
\frac{\alpha_{n+1}}{\alpha_n^2}\longrightarrow\frac12.
\]

The limit arises from exact cancellation of the doubly exponential error scale, leaving a prefactor quotient governed by \(A_{n+1}/A_n\to2\). A companion numerator-channel coefficient is recorded only as a numerical observation.
